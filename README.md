# Двигаемся. Думаем. Готовим сами.

Личный сайт Николая и основа будущего детского лагеря летом 2027 года.

## Три направления

- **Бег и физкультура:** движение, координация, выносливость.
- **Шахматы:** логика, внимание, стратегия и принятие решений.
- **Готовим сами:** самостоятельность и умение накормить себя и близких.

Кулинария: блины, карбонара, жареная картошка, лазанья, мясо по-французски и жаркое в горшочках.

## Структура

- `index.html` — главная страница и три направления.
- `style.css` — общие стили.
- `script.js` — активная навигация и доступный просмотр фото.
- `chess-analyzer.html`, `chess-analyzer.js` — существующий шахматный раздел.
- `main-page-chess.js` — статистика шахмат на главной.
- `main-page-runs.js`, `user-data.js` — заготовки для беговой статистики.
- `images/` — фотографии сайта, новый снимок с забега и иллюстрация кулинарии.
- `docs/ROADMAP.md` — дальнейшие задачи и ограничения текущей версии.

## Запуск на компьютере

Нужен Python 3. Из папки проекта:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Сборка и установка пакетов не требуются.

## Где сохраняются изменения

Код и существующие фотографии находятся в этом репозитории. История Git сохраняет зафиксированные версии: их можно сравнивать и восстанавливать. Изменения на компьютере попадут на GitHub после коммита и отправки (`push`), либо после сохранения через GitHub.

Папка OneDrive не синхронизируется с GitHub автоматически. Данные из `localStorage` также не попадают в репозиторий: они остаются в конкретном браузере.

## Подключения

Подключение Garmin, интеграции с Telegram и ботом «Девять касаний», общая база данных и новое размещение сайта отложены. Текущая ссылка на Telegram-канал сохранена. Существующие запросы к публичному API Chess.com оставлены без изменений.

Пароли, API-ключи, личные ответы боту и данные заявок не должны храниться в публичном репозитории. Файл `.gitignore` исключает обычные локальные файлы секретов; это не заменяет проверку перед коммитом.

## Оформление

Тёмная природная палитра, тёплые золотистые акценты, светлый кулинарный раздел и адаптация к телефону. Подробности и происхождение изображения для кулинарии — в `docs/DESIGN.md`.
