# Chess.com и Garmin

Chess.com: публичный профиль `peretoka73`. Главная загружает рейтинги Rapid/Blitz и сумму win/loss/draw для стандартных rapid, blitz, bullet и daily. Варианты шахмат не включены. Страница партий показывает до 100 последних партий из трёх последних доступных месячных архивов. Сохранённая серверная копия используется при недоступности API.

Garmin: официальный Personal API. Пароль Garmin сайту не требуется.

1. Открыть https://connect.garmin.com/app/settings/personalApiToken в своём аккаунте, создать персональный ключ.
2. В https://github.com/nvdemin073/run_chess_med/settings/secrets/actions создать Repository secret с именем `GARMIN_PERSONAL_API_KEY` и значением ключа.
3. В Actions открыть `Sync Chess.com and Garmin` и нажать Run workflow.
4. Проверить успешное выполнение и блок бега на сайте.

Ключ отображается Garmin только при создании; срок действия выбирается там же. После истечения заменить secret. Ключ не нужно присылать в чат или сохранять в коде.

Workflow обновляет данные каждые шесть часов и вручную. На публичный сайт из Garmin попадают только дата, дистанция, длительность и темп последних пробежек, количество и километраж за календарный месяц по дате начала тренировки Garmin. Маршруты, названия тренировок, координаты и показатели здоровья не публикуются. Полная история Garmin не загружается: берутся текущий и предыдущий месяцы.

Если API возвращает ошибку, прежний JSON не заменяется частичными данными источника. Ошибка синхронизации видна в Actions. Обновления Chess.com могут появляться с задержкой из-за кеширования самого Chess.com. Плановые GitHub Actions также могут запускаться с задержкой; в неактивном публичном репозитории расписание может отключиться после 60 дней без активности.

Источники:
- https://www.chess.com/news/view/published-data-api
- https://developer.garmin.com/gc-developer-program/personal/personal-api/
- https://github.com/garmin/connect-personal-api-python

На сайте есть тёмная страница `runs.html`: до 30 последних пробежек за текущий и предыдущий месяцы. Для перехода к отдельной тренировке сохраняется только её числовой Garmin ID. Внешний Garmin Connect использует собственное оформление.

Шахматы: по умолчанию показана статистика. Доска создаётся при выборе партии; просмотр ходов не является автоматическим анализом шахматным движком.
